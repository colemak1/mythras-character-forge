# Mythras Forge Core verification plan

Progress: **3/8 prior closeouts retained; subsystems 4 and 5 reopened for scope reconciliation**. Numbering is stable; partial work does not count as finished. A subsystem is finished only when its applicable Core rules and exceptions are inventoried, implementation or explicit GM handling is checked against the user's uploaded Core rulebook, meaningful automated cases pass, and relevant signed-in workflows are verified on the deployed revision. Open interpretations, unsupported behavior, and exclusions must be explicit. This is not a book-wide accuracy percentage.
