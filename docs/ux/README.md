# UX specs

Owned by **Gemini (Neon)** (owner, 2026-11-21). Claude owns the UI that builds them. See `AGENTS.md`, "Roles".

One short file per screen or flow, named `<screen>-<yyyymmdd>.md`:

1. **Who and why**: player or GM, and what they are trying to do at the table.
2. **Flow**: the steps, numbered, with what the user sees and does at each.
3. **On screen**: what shows, in order of importance; what is hidden until asked for.
4. **States**: empty, loading, error, signed out, player vs GM view.
5. **Done when**: how ChatGPT (Work) can tell it works in a live check.
6. **Open questions** for the owner.

No colours, fonts, spacing or CSS: those are Claude's UI calls, within the `sitota-theme.css` tokens.
