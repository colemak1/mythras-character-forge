# Career and bonus-skill audit

Authority: the user-uploaded `pdfcoffee.com_mythras-2e-2-pdf-free(20261021-212124).pdf`, Mythras Core Rulebook, printed pp. 28–34. The PDF's parsed text is garbled, so the career tables, custom-career box and age table were checked on rendered page images. This is an audit of the career and bonus-skill creation workflow, not a claim that every interaction or live workflow is verified. Starting equipment, magic and cult membership are tracked separately as CR-04.

| Case | Source and expected behavior | Implementation / evidence and outstanding work |
|---|---|---|
| CR-01a Career choice | p. 28: career is subject to GM suitability; the cultural-background table gives examples rather than a definitive restriction. | App allows all listed careers. GM suitability is a table decision; no approval record. Automated check of every cultural pairing and live test are open. |
| CR-01b Career choices | p. 28: choose up to three available professional skills, potentially including skills already obtained from culture; new ones start at characteristic base, with suitable specialities. | `professionalPicksError` validates available names and duplicate skill/speciality instances; skill keys merge career and culture. Tests exist for selected boundaries, not all career/culture/speciality combinations. Fixed hints are guidance and are not enforced as exact speciality values; needs GM review and an explicit product decision. |
| CR-01c Career points | p. 28: spend 100 among listed standard skills and selected professional skills, with at most 15 per individual skill; any listed skills may be left unimproved. | `careerKeys` and `validate` enforce a 100-point sum, 0–15 per eligible key and reject hidden allocations. Existing regression coverage is partial; systematically test each career and duplicate/linked style interaction live. |
| CR-01d Custom standards and styles | p. 33: up to seven standard skills, counting Combat Styles; GM agrees career. | The editor enforces seven combined and now allows zero through seven style slots. Tests cover seven versus eight, a three-style career, editing and saved allocations. Source advises granting styles where physical conflict is relevant; GM approval remains manual. No live test yet. |
| CR-01e Custom professional options | p. 33: up to seven professional skill options for the profession. | The editor now records seven separate option slots; the character may subsequently select up to three. Repeated specialised skill names can represent separate offers. Tests cover duplicate Lore, persisted selections, and removing an offer without silently deleting selected skill points. This records generic skill names, not prescribed speciality labels; GM review remains necessary. No live test yet. |
| CR-01f Older custom careers | Existing characters must retain their skills and points. | Legacy saves without an offer list remain usable. On editing, currently selected professional skills seed the new offer list; the user can add the other agreed options. Regression covers this migration. No cloud/live test yet. |
| CR-02 Career entries | pp. 29–33: 24 published career entries and their offers. | Names and offers visually compared against `js/data.js`; “Navigate” is normalized to Navigation. This is source review, not an entry-by-entry automated or live pass. A future fixture must independently transcribe and test each offer, including constrained specialities. |
| CR-03a Age table | p. 34: Young 100/+10/0 events; Adult 150/+15/1; Middle Aged 200/+20/2; Senior 250/+25/3; Old 300/+30/4. | Category pools, caps and event counts match the table in `AGE_CATEGORIES` and `coreBackgroundRollCount`; selected age/event flows have automated tests. The manually entered exact age can disagree with the chosen category and its pool. That is an open validation/GM-exception design issue; values are not silently altered. |
| CR-03b Bonus pool and hobby | p. 34: spend the age pool on known skills within its cap; choosing one additional professional skill or Combat Style is optional. | The hobby is now optional and the pool still requires full allocation to eligible skills at the applicable cap. Regression covers an adult with no hobby. More age bands, optional hobby specialities and signed-in save/reopen remain to be tested. |
| CR-03c Ageing and event rolls | pp. 34, 70–71: Senior/Old characters are subject to ageing; age determines background event rolls. | Existing GM-reviewed ageing and recorded background event workflows have automated cases. The full live GM/player flow and exact age/category mismatch remain open. |

Published careers inspected: Agent, Alchemist, Beast Handler, Courtesan, Courtier, Crafter, Entertainer, Farmer, Fisher, Herder, Hunter, Merchant, Miner, Mystic, Official, Physician, Priest, Sailor, Scholar, Scout, Shaman, Sorcerer, Thief and Warrior. Each still needs its own independent fixture and live evidence before being marked verified.

The automated checks are not signed-in workflows or evidence of deployment. See `core-rule-scope.md` for the broader inventory and separate evidence categories.
