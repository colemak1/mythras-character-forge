## Repeated specialities: source review

The uploaded Core p. 28 says to select up to three professional skills from a career's available skills and explains that some require a specialisation. The Warrior example on p. 29 selects two separately listed Lore skills, and pp. 44–48 describe distinct specialised instances (for example Art, Language, Literacy, Lore, Musicianship and Navigation). These establish that different specialities are separate skills and that two separately listed options can be selected. The reviewed text does not explicitly say whether a single `(any)` career option can be selected more than once. Project interpretation: allow different specialities to use separate selections from one broad offer, subject to GM agreement, and reject the exact same skill and speciality twice. Both published and custom careers follow this interpretation; it is not asserted as an explicit Core ruling.

The skill descriptions identify four previously missing creation prompts: Literacy (associated language, p. 47), Musicianship (instrument group, p. 48), Mysticism (foundation, p. 48), and Navigation (region or environment, p. 48). These now require a speciality in the professional-skill pickers and when chosen as a hobby. Existing saved unnamed skills are retained on load; naming one for the first time transfers its bonus points where the old instance is no longer shared. Automated tests cover these prompts and this migration; live verification is open. Literacy's language prerequisites and cap require a separate audit and are not implemented by these prompts.

Literacy follow-up: Core p. 47 requires the associated spoken language and caps Literacy at that Language skill. The character builder now flags this for manual GM review when Literacy is chosen in a professional picker or as a hobby. It does not yet link the language or calculate the cap; an explicit native-language identity and safe handling of existing stored allocations are needed before automating it.
