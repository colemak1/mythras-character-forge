## Live verification

Separate from rule accuracy: signed-in GM and player campaign creation, settings, permissions, save/reopen, import/export and persistence remain unverified. Do not mark passed based on mocked cloud calls.

## Measurement

Do not calculate a book-wide accuracy percentage from this chapter inventory. Break each area into meaningful rules and record source/page, expected behavior, code, tests, status and date first. Report source-verified coverage, implementation status and live verification separately. Avoid weighting a chapter as if every chapter had equal rules volume.
