# The Pits — Serious Wound to a weapon arm (2026-11-11)

**Source:** Owner's uploaded *Mythras 2e Core Rulebook* (printed pp. 88, 91–93, 109–110; PDF page = printed + 1). **Scope:** code-needed cases only; Claude owns implementation and tests. This is not a live-test report. Core wording is paraphrased.

| ID | Given X → Core p.N says Y | Code/test required |
|---|---|---|
| ARM-01 | **Given** a Serious Wound in either weapon-holding arm, **Core p.110** says a failed opposed Endurance test renders that arm useless until it has **positive HP**, dropping anything it holds unless strapped on. On a success it does **not** impose this drop/limb-disable result. Either way, for the next **1d3 turns** the victim cannot attack or start spells, but may parry/evade. | Record the **actual left/right holding hand** and Endurance outcome; drop only items held in a failed arm and not strapped. Prevent use/pickup by that arm until positive HP; never treat every Serious Wound as automatic disarm. Test a left-handed sword fighter as well as a right-handed one. |
| ARM-02 | **Given** a nearby weapon dropped after ARM-01, **Core pp.91–92** says Ready Weapon is proactive (1 AP **each turn**), and retrieval takes **two turns**: reach down for it, then recover a readied stance. **Core p.110** says the disabled arm remains useless. | Use a **functioning, free hand** to retrieve; charge **2 Ready Weapon turns / 2 AP** total, not an instant pickup. A disabled hand cannot perform either step. Treat a weapon farther away as requiring movement/reach first. |
| ARM-03 | **Given** a two-handed weapon and one failed/disabled arm, **Core p.110** makes that arm useless and drops what *it* holds unless strapped; **Core p.88** distinguishes two-handed weapon use. | Disallow attacks/parries requiring **both hands** while one is unusable. Do not necessarily erase the weapon if the good hand still grips it; allow one-handed use **only if that weapon has a legal one-handed mode**. No automatic swap or free re-ready of a weapon already dropped. |
| ARM-04 | **Given** a disabled shield arm, **Core p.110** exempts strapped items from dropping but makes the arm useless; **Core p.93** requires an available weapon/shield for deliberate Ward Location. | Keep a strapped shield attached but disallow its active parries, strikes and newly chosen wards with that arm. The healthy arm's one-handed weapon remains usable once the separate 1d3-turn attack restriction ends. Passive physical coverage by an immobile strapped shield is **GM-handled**, not automatically granted or discarded. |
| ARM-05 | **Given** a prepared second throwing weapon already held off-hand, **Core p.109** expressly permits swapping it to the throwing hand as a **Free Action**. | Keep that explicit zero-AP exception **only when the receiving hand works**. It cannot rescue a weapon that has already fallen from a disabled arm. Reverse left/right exactly for left-handed throwers. |

**Not stated as Core / no code decision yet:** A **melee** one-handed weapon transferred directly from one working hand to the other, while still held, is **not** given a universal AP cost or extra readying step on Core p.92 or p.109. The p.109 Free Action text is specific to a prepared off-hand **throwing** weapon. Proposed table policy, if owner approves: treat a direct hand-to-hand melee transfer as Free Action with **no separate Ready Weapon**, provided both arms can participate; label this an app/GM interpretation, **not** explicit Core RAW. Once the injured arm has failed Endurance and dropped its weapon, this proposal no longer applies: use ARM-02.

**Existing rule to retain:** a successful limb Endurance roll never automatically drops equipment; a disabled left arm is not assumed to be the shield arm, nor is the right arm assumed to be the weapon arm. Other existing wound/action cases need no new work unless these tests find a regression.
